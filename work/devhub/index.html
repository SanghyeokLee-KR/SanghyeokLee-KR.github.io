DevHub는 게시판과 코드 스니펫, 팀 모집, 포인트 충전과 출석, 실시간 채팅, AI 챗봇이 있는 개발자 커뮤니티입니다. Spring Boot와 Thymeleaf로 서버에서 화면을 그립니다.

끝난 뒤 다시 고친 것

꺼 두었던 Spring Security를 다시 켜고, 포인트와 기동 오류를 고쳤습니다

로그인은 세션에 아이디를 담는 커스텀 방식이라, Spring Security는 로그인한 사용자가 누구인지 몰랐습니다. 켜면 로그인한 사용자까지 막혀서 팀 프로젝트 때는 꺼 두었고, 그동안 프레임워크 수준의 인가는 없었습니다. 프로젝트가 끝난 뒤 요청마다 세션의 아이디를 SecurityContext에 올려 주는 필터를 넣고, 민감한 경로만 로그인을 요구하게 했습니다.

  • SecuritySecurity를 켜면 모든 요청이 막혔습니다세션 로그인 정보를 요청마다 SecurityContext에 올려 주는 OncePerRequestFilter를 넣고, 회원 수정 · 글쓰기 · 결제 · 출석 같은 경로만 authenticated()로 묶었습니다. 로그인하지 않았으면 /login으로 보냅니다.
  • 포인트음수를 빼면 포인트가 오히려 늘었습니다잔액에서 차감액을 빼는 식에 음수가 들어가면 오히려 더해졌고, 잔액이 차감액 이상인지 보는 조건도 늘 통과했습니다. 0 이하 차감은 거부하고 잔액이 충분할 때만 빼도록 고쳤고, 트랜잭션은 서비스 계층에 두었습니다.
  • 챗봇 키챗봇 키 파일이 없으면 앱이 뜨지 않았습니다키 파일은 .gitignore 대상이라 새로 클론하면 없는데, 기동할 때 챗봇 클라이언트를 무조건 만들고 있었습니다. 키 파일이 있을 때만 빈을 만들고, 서비스는 ObjectProvider.getIfAvailable()로 받아 키가 없으면 안내 문구를 돌려줍니다.
// SessionAuthenticationFilter · 요청마다 세션의 아이디를 인증 주체로
HttpSession session = request.getSession(false);
if (session != null
    && session.getAttribute("loginId") != null) {
  var auth = new UsernamePasswordAuthenticationToken(
      loginId, null, List.of(ROLE_USER));
  SecurityContextHolder.getContext()
      .setAuthentication(auth);
}
chain.doFilter(request, response);

// OrderService.deductPoints · 0 이하 차감 거부
if (MPoint <= 0) return 0;
if (currentPoints >= MPoint) { ... }

줄인 코드입니다. 전체는 저장소의 config/SessionAuthenticationFilter.java와 service/OrderService.java에 있습니다.

  • 키와 비밀번호를 설정에서 뺐습니다별도 설정 파일로 옮기고 .gitignore에 넣었습니다.
  • 업로드 경로를 바깥으로 뺐습니다방금 올린 프로필 사진이 바로 보이지 않던 문제였습니다. 저장과 제공 위치를 외부 uploads 폴더로 맞추니 바로 뜨고, JAR로 묶어도 동작합니다.
  • 접속 위치 조회 토큰을 서버로 옮겼습니다조회 토큰이 브라우저에 보이지 않게 서버가 대신 조회하고, 기록하는 IP도 요청에서 직접 뽑습니다.
  • 데모 데이터와 한 줄 실행H2 프로파일에서 회원 · 게시글 · 구매 · 출석 데모 데이터가 자동으로 들어가, 외부 키 없이 바로 둘러볼 수 있습니다.
  • 테스트 17건과 빌드 CIGitHub Actions가 JDK 21에서 빌드와 테스트를 돌립니다.

테스트로 묶은 규칙

인증 · 포인트 · 출석 · 검색 규칙을 테스트 17건으로 고정했습니다

무엇을확인하는 규칙건수
세션 로그인비밀번호가 맞으면 세션과 접속 이력이 남고, 틀리면 세션을 만들지 않습니다. 없는 아이디도 같은 문구로 답합니다.3
포인트 차감음수 차감은 거부하고, 잔액보다 큰 금액은 빼지 않으며, 잔액이 충분하면 그만큼만 뺍니다.3
출석 적립같은 날 두 번 출석해도 한 번만 쌓이고, 적립 포인트(일요일 100, 평일 10)는 서버가 정합니다.2
AI 챗봇 경로인증 키가 없어도 500 대신 안내 문구를 돌려줍니다.1
앱 기동외부 키 없이 애플리케이션 컨텍스트가 올라옵니다.1
게시판 검색제목 · 작성자 검색은 맞는 글만, 없는 키워드는 빈 목록을 돌려줍니다.3
접속 IP 조회토큰이 없으면 외부 조회 없이 IP만 남기는 등, 접속 이력에 남길 값을 정합니다.4
기존 세션 로그인 흐름은 그대로 두고, 필터 하나를 추가해 Spring Security 인가를 붙였습니다.
