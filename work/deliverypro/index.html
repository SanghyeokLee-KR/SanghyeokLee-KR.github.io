01개요

손님 · 사장님 · 라이더 · 관리자를 잇는 배달 플랫폼

손님은 가게를 골라 주문하고, 사장님은 주문을 받아 메뉴를 관리합니다. 라이더는 배달을 맡고, 관리자는 회원과 가게, 라이더를 관리합니다. 이 네 역할을 한 서비스로 잇는 배달 플랫폼을 다섯 명이 만들었습니다.

조장인 저는 라이더 한 명이 여러 집을 어떤 순서로 돌지 서버가 계산하게 만들었고, 다섯 명이 짠 API가 같은 모양으로 응답하도록 공통 규약을 정했습니다. 소셜 로그인과 화면도 맡았습니다.

14.58km

배달지 5곳을 도는 경로

데모용 격자 도로망에서 약 38분 걸리는 순서입니다.

1,876m

직선으로 208m인 두 집의 도로 거리

건널 수 없는 길을 우회한 거리입니다.

02묶음배달 경로 계산

라이더가 어느 집부터 들러야 할지, 서버가 계산하게 했습니다

직선거리로 순서를 정하면 일방통행도, 건널 수 없는 길도 알 수 없습니다. 그래서 도로망을 방향 그래프로 만들고, 그 위에서 정차지끼리 걸리는 시간을 구한 뒤 순서를 정했습니다. 도로망은 실제 지도가 아니라, 일방통행과 건널 수 없는 길을 넣은 25×21 데모용 격자입니다.

  1. CSR graph

    방향이 있는 도로망

    교차로를 노드, 도로 구간을 간선으로 두고, 간선에는 거리 대신 도로 종류별 속도로 구한 소요 시간을 넣었습니다.

  2. snap · 400m

    가까운 교차로에 붙이기

    배달지를 400m 격자 색인으로 가장 가까운 교차로에 붙이고, 1,500m 넘게 떨어지면 구역 밖으로 봅니다.

  3. Dijkstra

    정차지마다 한 번

    정차지끼리 걸리는 시간표를 만듭니다. 다른 정차지를 모두 찾으면 탐색을 멈춥니다.

  4. Held-Karp

    방문 순서

    12곳까지는 정확한 답을 구합니다. 그보다 많으면 최근접 이웃과 2-opt 근사로 바꾸고, 정확한 답인지 응답에 표시합니다.

  1. 순서와 경로를 한 번에계산한 순서는 DB에 저장하고 구간 좌표와 함께 돌려줘, 화면의 경로와 저장된 순서가 어긋나지 않게 했습니다.
  2. 같은 교차로에 붙은 두 집교차로까지 걸어가는 거리를 도보 속도로 바꿔 구간 양 끝에 더했습니다. 그래야 같은 교차로에 붙은 두 집 사이가 0초로 나오지 않습니다.

03테스트로 고정

일방통행이 반영되는지 확인한 테스트

그래프 계산은 우회해야 하는 두 집으로 확인했습니다. 건널 수 없는 길 양쪽에 있어서, 직선으로는 가깝지만 도로로는 한참 돌아가야 하는 곳입니다. 같은 두 집이라도 가는 방향에 따라 시간이 달라야 일방통행이 비용에 들어갔다고 할 수 있습니다.

직선으로 재면

208m

두 집을 곧게 이은 거리입니다.

도로를 따라가면

1,876m

건널 수 없는 길을 피해 돌아가는 우회로입니다.

갈 때

247.7초

한쪽 방향으로 갈 때 걸리는 시간입니다.

올 때

97.6초

반대 방향은 두 배 넘게 빠릅니다.

이 값을 테스트의 기댓값으로 넣었습니다. 도로망 데이터가 바뀌면 이 테스트가 실패합니다. 방문 순서도 모든 순서를 다 따져 본 답과 같은지 테스트로 확인합니다.

04서버 공통 규약

다섯 명이 만든 API가 같은 모양으로 응답하게 맞췄습니다

처음에는 API마다 응답 모양이 달랐고, 실패를 null이나 true/false로 알리는 곳도 있었습니다. 그래서 응답은 ApiResponse 하나로 감싸고, 실패는 오류 코드 여덟 개와 BusinessException 하나로 알리게 정리했습니다.

상태오류 코드
400BAD_REQUEST
400VALIDATION_ERROR
401UNAUTHORIZED
403FORBIDDEN
404NOT_FOUND
405METHOD_NOT_ALLOWED
409CONFLICT
500INTERNAL_SERVER_ERROR
  1. 기존 핸들러와의 충돌 방지이름이 같은 예전 핸들러가 남아 있어서, 새 핸들러는 이름을 따로 주고 @RestController에만 걸리도록 범위를 좁혔습니다.
  2. 트랜잭션은 서비스에서트랜잭션 경계를 서비스 계층으로 옮기고 조회에는 readOnly를 붙였습니다. open-in-view를 꺼서 지연 로딩이 화면까지 새어 나가지 않게 했습니다.
@RestControllerAdvice(name = "restGlobalExceptionHandler",
                      annotations = RestController.class)
public class GlobalExceptionHandler {
    @ExceptionHandler(BusinessException.class)
    ... ApiResponse.fail(errorCode, ex.getMessage())
}

05로그인과 실행

소셜 로그인 3사 연동과 로컬 실행

소셜 로그인 3사Apache HttpClient

네이버 · 구글 · 카카오의 인가 코드 교환과 프로필 조회를 직접 호출합니다. 카카오만 응답 구조가 달라 따로 읽고, 비밀번호는 BCrypt로 저장합니다.

Oracle 없이도 실행h2 프로파일

H2를 Oracle 호환 모드로 띄우고 데모 데이터를 넣습니다. 데모 데이터는 이 프로파일에서만 들어갑니다.

지도 키 없이 경로 표시SVG

키가 없으면 서버가 계산한 경로를 SVG로 그립니다. 외부 키 없이도 경로 계산 결과를 확인할 수 있습니다.

./gradlew bootRun --args='--spring.profiles.active=h2'
Oracle과 외부 API 키 없이, H2 메모리 DB와 데모 데이터로 뜹니다
